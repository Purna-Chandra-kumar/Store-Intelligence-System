# Event Schema Reference

All events share this envelope:

```json
{
  "event_id":   "uuid",
  "event_type": "<see below>",
  "timestamp":  "ISO-8601 UTC",
  "camera_id":  "cam-01",
  "track_id":   17,
  "zone":       "checkout",
  "metadata":   { /* type-specific */ }
}
```

## Event types

### `person_entered`
First time a track_id is observed on a camera.
- `metadata.foot`: `[x, y]` foot point in image px

### `person_exited`
Track disappeared and was not reacquired within `lost_track_buffer` frames.
*(Currently inferred at zone level — see roadmap.)*

### `zone_entered` / `zone_exited`
A tracked person crossed into / out of a configured polygon.
- `metadata.zone_name`: human label
- on `zone_exited`: `metadata.dwell_seconds`

### `queue_detected`
Emitted every frame a `queue` zone has ≥ `min_people`.
- `metadata.queue_length`: int
- `metadata.wait_seconds`: int (estimate)

### `crowd_detected`
Live count exceeded `multiplier × rolling baseline` (see `pipeline.yaml`).
- `metadata.live_count`, `metadata.baseline`

### `loitering_detected`
A track has been continuously inside a zone longer than `loitering.seconds`.
- `metadata.seconds`

### `anomaly_detected` (kind=stationary)
Track foot point did not move > `stat.px_radius` for > `stat.seconds`.
- `metadata.seconds`

### `frame_stats`
Periodic snapshot (every 2s). Powers the dashboard.
- `metadata.live_count`
- `metadata.occupancy`: `{ zone_id: count }`
- `metadata.heatmap`: `{ cols, rows, values[] }`
- `metadata.tracks`: `[{ id, xyxy }]`

## Idempotency

`event_id` is a UUIDv4 generated by the producer. The backend uses it as
the primary key, so re-delivery from Redis is naturally deduped.
